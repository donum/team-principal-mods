# Plan: F1 2010 to 2013 (the Vettel years)

Our first Formula 1 packs, on one era base `bases/f1-v8`. 2012 is first.
The plan is written so a new session can continue without the earlier
conversation.

## Goal for 2012

Play the 2012 story: the Pirelli tyres made the first half a lottery
(seven different winners in the first seven races), then Red Bull's
upgrades made Vettel very hard to beat (four wins in a row from Singapore).
In the pack this should come out of the game by itself, measured with
`tools/simulate.py`:

| Check (per simulated season) | Target |
|---|---|
| Different winners, rounds 1-10 | 5 or more |
| Different winners, rounds 11-20 | 4 or fewer (real: 4) |
| Red Bull share of points, rounds 11-20 | among the top two (real: Red Bull 230, Ferrari 223, McLaren 218) |
| Vettel wins, rounds 11-20 | the most of any driver, with a run of wins (real: 4 in a row) |
| Pole times | within about 2% of the real 2012 poles |

## Why this works in the game (findings)

Read from the game's code (0.99.6, `private/game_code`):

- **The tyre temperature window is weak.** Outside `temp_window_c` a tyre
  loses 0.005% grip per degree too cold and 0.025% per degree too hot,
  fixed in the code. The target temperature is ambient + 70 °C + the
  pressure setup, the same for every car. So narrow windows alone can't
  make the 2012 chaos (wishlist D10). The base still uses lower, narrower
  windows, which bite on hot days.
- **Weekend variability is the shuffle.** `WEEKEND_CORNERING_VARIABILITY_*`
  gives each driver a random cornering offset per weekend:
  uniform(-span, +span) km/h, span = level × km/h per level. The level is
  the player's option (`variability_level`), clamped to the pack's
  `LEVEL_MIN`..`LEVEL_MAX`. Vanilla: min 1, 0.25 km/h per level. The base
  sets min 3 and 0.6 km/h per level, so every weekend has a real shuffle.
  These names are on the Workshop whitelist (`workshop_constant_names`).
- **Car profiles make the order depend on the track.** Each top car is
  strong on a different kind of corner (`profiles` in
  `seasons/f1-2012/gen.json`): McLaren and Red Bull in fast corners,
  Ferrari and Mercedes on straights and traction, Lotus and Sauber on tyre
  wear. With base ratings within about a point, the track decides.
- **Development decides the second half.** `chassis_starting_potential`
  (generator: a team's `potential`) is the headroom for in-season
  development. Red Bull gets the most headroom, the best staff (level 18),
  wind tunnel 5 and a big budget. Watch out:
  `CHASSIS_DEV_CURRENT_PACKAGE_CATCHUP_*` slows a team that is ahead
  (0.95x) and speeds up those behind (1.05x); if Red Bull can't pull away,
  set `..._AHEAD_BASE_MULT` to 1.0 (also whitelisted).
- **Driver skill dominates when cars are equal.** The DTM 2013 sims gave
  3-5 winners out of 10 with cars within 2 points, because the two best
  drivers won most. So the top F1 drivers are set close together by hand
  (`drivers` in gen.json), with traits from their 2012 reputation
  (Button and Pérez `tyre_whisperer`, Grosjean and Maldonado
  `crash_happy`).

## Layout

```
bases/f1-v8/            F1 2010-2013 (2.4 V8, the last years before the turbo hybrids)
  base.json             default26 as base pack, constants (grid 24, variability)
  gen.json              engines (Renault, Ferrari, Mercedes, Cosworth), Pirelli,
                        generator defaults (make = engine supplier)
  patches/regulations.json   knockout, DRS, KERS as spec ERS, no refuelling,
                        640 kg, 11 dry sets, no scripted vanilla rule changes
  data/tyremodel.json   Pirelli wear, cliffs and windows
  track_specs/ tracks/ assets/tracks/   OSM-traced circuits, shared by all years
seasons/f1-2012/
  gen.json              teams (rating, profile, potential, staff, HQ, budget,
                        vanilla clone, chassis names), driver skills, calendar
  research/             sourced facts: calendar, entries, standings, results
```

The vanilla game is a fictional modern F1, so most of the base pack fits
as it is: economy, sponsors pool, staff roles, parts. Each real team takes
the secondary settings of one vanilla team (`clone`).

## Steps

1. **Research** (`seasons/f1-20xx/research/`): calendar, entries (with
   Friday drivers as reserves), standings, per-round results for 2012,
   `season.md`. Done for 2012 first, then 2011, 2013, 2010.
2. **Tracks** (`bases/f1-v8/track_specs/`, `tools/osm_track.py`): the 20
   circuits of 2012 plus Istanbul and the Nürburgring. Then calibrate
   `speed_scale` against the 2012 poles: run a short sim, compare
   `report.md`'s pole column, `new = old × sim_pole / real_pole`, re-run
   `osm_track.py`.
3. **Generate and build:**

   ```bash
   python -I tools/season_from_research.py seasons/f1-2012
   ```

   ```bash
   python -I tools/build_pack.py seasons/f1-2012
   ```

4. **Simulate and tune** (about an hour per season, runs in parallel):

   ```bash
   python tools/simulate.py f1-2012 --runs 6
   ```

   The report now has "First half and second half" and "Car development"
   sections (team_pace after each race, from `cars.jsonl`). Tune in this
   order: base ratings (start order), weekend variability (first-half
   winners), potential and catch-up (second half), driver skills.
5. **Install and play** (`--install`), check in the game what the sim
   can't show (screens, names, chassis names, tyre allocation screen).
6. **Art** (later, needs the user): car side views, team logos, portraits,
   engine and tyre logos, menu background.
7. **Sponsors**: real 2012 sponsors per team (`sponsors` in gen.json, as in
   DTM 2013). Avoid tobacco brands.
8. **2011, 2013, 2010**: a `gen.json` per year on the same base. Most team
   blocks carry over with new ratings and drivers. Differences:
   - 2013: Nürburgring instead of Valencia, no COTA change; the tyre
     construction change after Silverstone (no data way to switch mid-season,
     wishlist D12); DRS only in its zones in qualifying too.
   - 2011: Istanbul and the Nürburgring, Valencia; Lotus Renault GP and
     Team Lotus naming; exhaust-blown diffusers (Red Bull dominant all year).
   - 2010: Bridgestone (own tyre model and supplier), no DRS
     (`drs_policy` disabled), no KERS (`ers_policy` disabled), refuelling
     already banned; Bahrain endurance layout, Istanbul, Valencia, Korea.

## Open questions for the game

- Does the knockout format cut 24 cars to 17 and 10 as in 2012? Check in
  a session.
- Does `engine_contract_type` "partner" for Red Bull and Renault do what
  we want (no works engine dev for a customer team)?
- With the 545 kg chassis minimum plus 95 kg engines the cars are about
  160 kg lighter than vanilla's. Track `speed_scale` absorbs the lap time,
