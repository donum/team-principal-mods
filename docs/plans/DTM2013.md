# Plan: DTM 2013 season pack

This is the next season pack. 2013 is the period whose rules match the game
best (see the "Closest to the game's rules" ranking in the season archive and
[docs/ERAS.md](../ERAS.md)). The plan is written so a new session can execute
it without the earlier conversation.

## The 2013 facts (from the research and the spotter guide)

**Format.**
- One race per weekend.
- Points 25-18-15-12-10-8-6-4-2-1.
- **Qualifying:** Q1–Q3 knockout plus a Q4 single-lap shootout. The game
  approximates the shootout with knockout.
- **Pit stops:** 2 mandatory, no pit window, none in the first or last 3
  laps. No refuelling (120 L tank).
- **DRS:** introduced this year, off for the last 3 laps.
- **Tyres:** Hankook only. The option (soft) tyre must be used once.
- **Cars:** 1,110 kg with driver. No success ballast.

## Steps

### 1. Rules template for the modern era
`season_from_research.py` currently takes rules from `dtm-1991`.
- Add a `rules_template` option to `gen.json`, or give 2013 its own
  `patches/regulations.json` and `season.json` constants. Settings:
  - `drs_policy: enabled`
  - `formula_compound_usage: enabled`
  - `formula_refueling: banned`
  - `qualifying_format: knockout`
  - `points_system: modern_top10` (the game's default)
  - `formula_team_entry_cap: two`, `formula_team_entry_requirement: fixed`
  - `driver_aid_restrictions: full_prohibition`
  - a car profile for Class One cars (about 500 hp, 1,110 kg, more downforce
    than Group A). Start around a 0.9 corner multiplier and calibrate.
- **Constants:**
  - `SEASON_START_YEAR = 2013`
  - `POINTS_TOP10 = [25,18,15,12,10,8,6,4,2,1]`
  - `QUALI_GRID_LIMIT = 22`
  - retirement ages left near the base values.
- **Engines:** Audi, BMW, Mercedes-AMG as works suppliers with equal-ish
  ratings. Real 2013 results: BMW won the manufacturers' title, Audi had the
  champion (Rockenfeller).
- **Tyres:** Hankook only, with soft (option) and hard compounds. Mirror the
  real option-tyre gap (1–1.5 s per lap) in the tyre model.
- **Economy:** salaries and budgets at a DTM scale (works teams). Keep the
  game's currency; note this in the README.

### 2. Generate the season data
- Write `seasons/dtm-2013/gen.json`: team names, colours from the liveries,
  `works: true` for all teams, track mapping.
- Run `python -I tools/season_from_research.py seasons/dtm-2013`.
- **Check:** 11 teams with 2 seats each, 22 drivers, numbers as in the list
  above, ratings in line with the final standings.

### 3. Tracks
- **New, from OSM raceway loops** (`tools/osm_track.py`, raceway-loop mode
  where OSM has a closed one-way loop, otherwise via mode), with
  `race_laps` set from `calendar.csv`:
  - Brands Hatch Indy (1.929 km)
  - Red Bull Ring
  - Lausitzring (2013 DTM layout, check its length)
  - Moscow Raceway (2.555 vs 2.661 km conflict in the research)
  - Oschersleben
  - Zandvoort
- **Hockenheim 2013:** today's short GP circuit (4.574 km, post-2002). This
  is a new spec: the raceway-loop mode probably works, with the 1991 forest
  loop excluded.
- **Norisring:** shared from 1991.
- **Nürburgring 2013:** the GP circuit **with** the Mercedes Arena, unlike
  1991. New spec, about 3.6 km (check which layout DTM used).
- Add the DRS zones in each track JSON (`drs_zones`: detection, start and
  end progress), from the 2013 DRS zones. 1991 tracks have none.

### 4. Car images (largest step)
- **New reference outlines:** trace side views from free Commons photos with
  the trace format of `seasons/dtm-1991/art/audi_v8_trace.json` and
  `car_art.traced_reference()`. Credit each photo.
  - Audi RS5 DTM
  - BMW M3 DTM (E92)
  - Mercedes AMG C-Coupé
  - Check Wikimedia Commons for clean side views of each.
- **Liveries:** no AMS2 textures exist for 2013. Extend `car_art.py` with a
  layered livery format:
  - base colour, colour zones (polygons on the side view), stripes
  - text decals (sponsor wordmark, font, colour, position, rotation)
  - number board
  - Use the spotter guide only to read colours and positions, and draw our
    own shapes and lettering. Aim for each car to be recognisable at a
    glance.
- Render all 22. Make a contact sheet and get the user's feedback.

### 5. Logos and portraits
- **Logos:** `tools/logo_art.py`.
  - Team logos from Commons where free: e.g. Abt Sportsline, Schnitzer,
    HWA/AMG.
  - Engine logos: Audi rings, BMW roundel (1997 version), Mercedes star
    (2009+ version). Check each period.
  - Crests as the fallback.
- **Portraits:** `python tools/portrait_art.py seasons/dtm-2013`. Most 2013
  drivers have free Commons photos close to 2013.

### 6. Build, document, commit
- `python -I tools/build_pack.py seasons/dtm-2013 --install`. This also
  rebuilds the mod browser (`private/mod_browser/dtm2013/index.html`, from
  `tools/mod_browser.py`), so it always shows what is installed. Look it over
  after every change to the mod.
- **Documentation:**
  - `seasons/dtm-2013/README.md`
  - `credits.txt`, crediting the Commons photos and the reference outlines.
    Mention that the spotter guide was used as reference only.
  - add the pack to the table in `README.md`
  - `python -I tools/build_browser.py`, then republish the season archive
    (Artifact URL https://claude.ai/artifact/A4xhX59jCcB7YfWWw4fS2p,
    file `build/season-browser/index.html`).
- **Commit** with the attribution line from the session's instructions.

### 7. In-game check (when the user is home)
- DRS works, the option tyre is used, and the race has 2 stops.
- Qualifying uses knockout.
- Lap times: calibrate with `tools/calibrate.py` against the real 2013
  poles. Real pole and race times are in `research/` if collected. If not,
  collect them first, like `seasons/dtm-1991/research/results/`.
